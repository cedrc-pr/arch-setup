# Overview

This project is a simple bash script that configure a fresh arch linux install.

# To use it

Run the commands:

```shell
chmod +x script.sh
./script.sh
```

# Why does it exists?

I'm the type of guy who like to reset his OS.

And sometimes, I show/share my setup to friends.

So this repo exists to share it to:

- me when I'm reseting my laptop
- friends who would like to pick some of it
